# FARLO — site

Site institucional da FARLO (sites com 3D e automações), publicado com GitHub Pages em https://farlo.online.

- HTML, CSS e JS puros, sem build. Abre também por `file://`.
- `index.html` / `en/index.html`: home PT e EN. Textos em `js/content.js`.
- `js/home3d.js`: 3D do hero (three.js carregado sob demanda) e demo da residência.
- `residencia-3d/`: demo 3D interativa embutida na home.

## Antes de divulgar

Trocar em `js/content.js`: `whatsapp` (55 + DDD + número), `email` e `instagram`.

## Créditos dos modelos 3D

Modelos (câmera, sofá, poltrona, mesa, planta, árvore) e texturas de [Poly Haven](https://polyhaven.com), licença CC0.
